Taber.js

A lightweight and simple tab library built with pure JavaScript ES6.

Try It Out

Taber is a lightweight tab library built with pure JavaScript ES6. (Source code available on GitHub)

  • No dependencies
  • Fully customizable with CSS (Zero extra CSS files needed)
  • Supports URL state persistence
  • Simple and intuitive API
  • Lightweight and optimized
